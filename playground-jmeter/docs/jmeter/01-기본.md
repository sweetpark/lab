# JMeter 기본 - 설치 및 첫 번째 테스트

## 1. JMeter란?

Apache JMeter는 Apache 재단이 만든 오픈소스 성능 테스트 도구입니다.

- **목적**: 서버, 네트워크, 애플리케이션의 성능/부하/스트레스 테스트
- **특징**: GUI 기반으로 코드 없이 테스트 계획 작성 가능
- **지원 프로토콜**: HTTP/HTTPS, JDBC, FTP, WebSocket, gRPC 등

---

## 2. 설치

### 사전 요구사항

- **Java 8 이상** 필수 (JMeter 5.x는 Java 8+, 권장 Java 11+)

```powershell
# Java 버전 확인
java -version
```

### JMeter 다운로드 및 설치

1. [Apache JMeter 공식 다운로드](https://jmeter.apache.org/download_jmeter.cgi) 접속
2. **Binaries** 섹션에서 `apache-jmeter-5.x.x.zip` 다운로드
3. 원하는 경로에 압축 해제 (공백 없는 경로 권장)

```
C:\tools\apache-jmeter-5.6.3\   ← 권장
C:\Program Files\jmeter\         ← 공백 포함 경로, 문제 발생 가능
```

### 디렉토리 구조

```
apache-jmeter-5.6.3/
├── bin/
│   ├── jmeter.bat       ← Windows GUI 실행
│   ├── jmeter.sh        ← Linux/Mac GUI 실행
│   └── jmeter           ← CLI 실행
├── lib/
│   └── ext/             ← 플러그인 설치 위치
├── docs/
└── extras/
```

## 3. JMeter GUI 실행

```powershell
# Windows
C:\tools\apache-jmeter-5.6.3\bin\jmeter.bat

# 또는 탐색기에서 bin\jmeter.bat 더블클릭
```

> **주의**: `jmeter.bat`을 직접 실행하면 콘솔 창이 함께 뜹니다. 이 창을 닫으면 JMeter도 종료됩니다.

## 4. GUI 화면 구조 이해

```
┌─────────────────────────────────────────────────────────┐
│  [메뉴바] File / Edit / Search / Run / Options / Help    │
├────────────────┬────────────────────────────────────────┤
│                │                                        │
│  [왼쪽 트리]   │  [오른쪽 설정 패널]                    │
│                │                                        │
│  Test Plan     │  선택한 요소의 설정값 편집               │
│  ├─ Thread Group                                        │
│  │  ├─ HTTP Request                                     │
│  │  └─ Summary Report                                   │
│  └─ ...                                                 │
│                │                                        │
├────────────────┴────────────────────────────────────────┤
│  [하단 상태바] 실행 중인 스레드 수 / 에러 수 표시         │
└─────────────────────────────────────────────────────────┘
```

### 주요 메뉴

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| File → Open | `Ctrl+O` | 기존 .jmx 파일 열기 |
| File → Save | `Ctrl+S` | 현재 계획 저장 |
| Run → Start | `Ctrl+R` | 테스트 실행 |
| Run → Stop | `Ctrl+.` | 테스트 중지 (graceful) |
| Run → Shutdown | - | 즉시 강제 종료 |
| Run → Clear All | `Ctrl+Shift+E` | 결과 초기화 |

## 5. 첫 번째 테스트 만들기 (Hello World)

### Step 1: Test Plan 생성

JMeter를 실행하면 기본으로 빈 `Test Plan`이 있습니다.
오른쪽 패널에서 이름을 `나의 첫 번째 테스트`로 변경합니다.

### Step 2: Thread Group 추가

Thread Group = 가상 사용자 집합입니다.

1. 왼쪽 트리에서 `Test Plan` 우클릭
2. **Add → Threads (Users) → Thread Group** 선택

오른쪽 패널에서 설정:

| 설정 | 값 | 의미 |
|------|----|------|
| Number of Threads | `5` | 동시 가상 사용자 5명 |
| Ramp-up period | `5` | 5초에 걸쳐 5명 순차 시작 (1초에 1명씩) |
| Loop Count | `3` | 각 사용자가 3번 반복 |

> **Ramp-up이 중요한 이유**: 모든 사용자가 동시에 시작하면 순간 스파이크가 생겨 현실적이지 않습니다. 실제 트래픽처럼 점진적으로 증가시킵니다.

### Step 3: HTTP Request Sampler 추가

Sampler = 실제로 보낼 요청입니다.

1. `Thread Group` 우클릭
2. **Add → Sampler → HTTP Request** 선택

오른쪽 패널에서 설정:

| 필드 | 값 |
|------|----|
| Server Name or IP | `localhost` |
| Port Number | `8090` |
| HTTP Method | `GET` |
| Path | `/api/products` |

### Step 4: Listener 추가 (결과 보기)

Listener = 결과를 수집/시각화하는 컴포넌트입니다.

1. `Thread Group` 우클릭
2. **Add → Listener → Summary Report** 선택

### Step 5: 실행

1. `playground-jmeter` 앱이 실행 중인지 확인 (port 8090)
2. `Ctrl+Shift+E` 로 기존 결과 초기화
3. `Ctrl+R` 로 테스트 실행
4. `Summary Report` 클릭하여 결과 확인

## 6. 기존 JMX 파일 열기

이 모듈에 이미 작성된 테스트 파일을 사용하는 방법:

```
File → Open → playground-jmeter/jmeter/plans/01-crud.jmx
```

파일을 열면 미리 구성된 Thread Group, Sampler, Listener가 로드됩니다.

---

## 7. 파일 저장

테스트 계획을 수정했다면 반드시 저장합니다.

```
File → Save As → 원하는 경로에 .jmx 파일로 저장
```

> JMeter 테스트 파일은 `.jmx` 확장자를 가진 **XML 파일**입니다. 텍스트 편집기로도 열고 편집할 수 있습니다.

## 8. 요약

| 개념 | 설명 |
|------|------|
| Test Plan | 테스트 전체를 담는 최상위 컨테이너 |
| Thread Group | 가상 사용자 집합. 동시 사용자 수와 반복 횟수 설정 |
| Sampler | 실제로 서버에 보낼 요청 (HTTP, JDBC 등) |
| Listener | 결과를 수집하고 보여주는 컴포넌트 |
| .jmx 파일 | 테스트 계획을 저장한 XML 파일 |
